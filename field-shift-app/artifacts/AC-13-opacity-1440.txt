# AC-13 (R-17) opacity, 1440x900, computer use

Method: the real app in Chromium at 1440x900, dev server on 127.0.0.1:5199, backend on
127.0.0.1:8001 (block 4 wave 1). Measured with CDP `Emulation.setDeviceMetricsOverride`,
DOM reads and `map.getPaintProperty` on `window.__fsMap`.

The card forbids PNGs in the repository, so this file carries the readouts the criterion
asks the screenshot to show. The measurements below are the ones AC-13 names.

```
Step 1, the layer is on at first paint (smap-l3, the block 1 layer):
  map.getPaintProperty('smap-l3-raster','raster-opacity') = 0.55
  opacity control value                                   = 0.55
  count of style sources                                   = 6

Step 2, the opacity control is set to 0.3 with a pointer-equivalent input event:
  input.value dispatched                                  = 0.3
  map.getPaintProperty('smap-l3-raster','raster-opacity') = 0.3
  opacity control value                                   = 0.3
  count of style sources                                   = 6
  source id list unchanged                                 = true
  addSource calls during the step                           = 0
  removeSource calls during the step                        = 0

Style layer tail after the step (raster layers sit above the basemap symbols):
  label_city, label_city_capital, label_country_3, label_country_2,
  label_country_1, smap-l3-raster
```

Verdict: `getPaintProperty` returns the value the control holds (0.3), the start value of a
layer that is on is 0.55, and neither a source nor a style layer was removed or re-added.

Reproduce: open the app at 1440x900, expand `Layer options, SMAP soil moisture`, set
`Opacity, SMAP soil moisture` to 0.3, read `window.__fsMap.getPaintProperty('smap-l3-raster','raster-opacity')`.

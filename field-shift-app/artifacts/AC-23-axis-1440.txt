# AC-23 (R-28), the axis, the default, the ?date= pin and the clamp, 1440x900

Method: the real app in Chromium at 1440x900, dev server 127.0.0.1:5199, backend
127.0.0.1:8001, plus `npx vitest run` for the same rules in jsdom.

The axis comes from `GET /layers` (`axis: {start, end, default}`) and the store keeps
`chosenDate: null` meaning "the axis default", so no control invents a date.

## A. Default load, no query

```
url                                = http://127.0.0.1:5199/
`Go to date` value                 = 2026-11-14
`Go to date` min / max             = 2015-04-01 / 2026-11-14
`Timeline date` aria-valuetext     = 2026-11-14, 3 days old
season label                       = 2026/27
status region                      = absent (no clamp happened)
```

## B. `?date=2026-11-12`

```
url                                = http://127.0.0.1:5199/?date=2026-11-12
`Go to date` value                 = 2026-11-12
`Timeline date` aria-valuetext     = 2026-11-12, 1 day old
season label                       = 2026/27
/`layers` request                  = GET /layers?date=2026-11-12 (recorded from the fetch log)
status region                      = absent
```

## C. `?date=2015-03-01`, before the axis start

```
url                                = http://127.0.0.1:5199/?date=2015-03-01
`Go to date` value                 = 2015-04-01
`Timeline date` aria-valuetext     = 2015-04-01, today
season label                       = 2014/15
role="status" text                 = Date limited to 2015-04-01
```

The live region is mounted only while a clamp message is owed, so at a normal load the DOM
holds no `role="status"` node.

## D. Typing a date outside the axis into `Go to date`

The date input carries min 2015-04-01 and max 2026-11-14 (R-45). A typed 2015-03-01 clamps
to 2015-04-01 and raises the same polite message. Covered by
`src/components/TimelineDock.test.tsx > clamps a typed date outside the axis and says which
bound it used (AC-23)`.

## Note on the axis values

The axis bounds are the registry's own (latest declared_end of any layer, 2026-11-14), read
from the `/layers` response. The recorded fallback axis in
`artifacts/fixtures/layers-response-2026-11-12.json` carries the same three values, so the
first paint before `/layers` answers shows the same bounds.

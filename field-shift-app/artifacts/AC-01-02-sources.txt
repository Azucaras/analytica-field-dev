# AC-01 and AC-02: the region adapter and the polygon sources over the basemap

Measured on 2026-11-14 in the built app (`dist/`, served with HTTP byte-range support on
http://127.0.0.1:5181), backend on http://127.0.0.1:8021 with `POLYGON_DIR` pointing at
`field-shift-app/data/polygons`. The products are the build of card t_aa25032c.

`?region=br` in the URL, the default load kept an empty query string.

## Not verified: the overview tier draws

The overview source mounts with the bounds of Table B and its four layers exist (the style
lists both overview layers). The United States overview archive carries three tiles, one per
overview zoom, from the build card's own reader:

```
z3 x1 y2 length=266 run=0
z4 x3 y5 length=530 run=266
z5 x7 y11 length=806 run=796
```

At map zoom 4.2 the map rendered 12 frames, requested no overview tile and returned zero
overview features; a probe source and layer added to the running map, with the same archive
and no zoom bound of its own, also returned zero features and issued no tile request. The
detail tier of the same session drew normally at zoom 11. The cause was not established in
this card. AC-04 and AC-06 belong to the gate and to the build card; this card claims only
that the overview tier is mounted with the contract's bounds and layers.

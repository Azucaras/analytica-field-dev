Reading of R-43 that this run enforces
-------------------------------------
R-43 says block 4 renders no basemap change, so the adapter is a boundary and not a wiring: the
test asserts that no module outside `src/lib/basemap-adapters.ts` names a Google host and that no
component imports the adapters. The visible basemap of the app is therefore still block 3's vector
style, and the live load above shows it: {"127.0.0.1": 74, "tiles.openfreemap.org": 15}.
A reader must not read this criterion as 'the satellite basemap renders EOX in block 4'; F-29 moves
that rendering to block 5, and CO-B4-05 carries it.

What this run does not claim
---------------------------
- No EOX tile request exists to measure, because nothing renders the adapter in block 4.
- The Google adapter is never exercised against Google; the criterion only requires that it is inert
  without the key, which the tests measure.

# AC-37 (R-26) layer row keyboard, 1440x900, computer use

Method: the real app in Chromium at 1440x900. Every key below was dispatched through CDP
`Input.dispatchKeyEvent`, so it is a trusted key event, not a synthetic DOM event. Focus is
read from `document.activeElement`.

```
Action                                        Result                                                Focus after
----------------------------------------------------------------------------------------------------------------------
focus `Layer options, SMAP soil moisture`     tabIndex 0 (native button)                            Layer options, SMAP soil moisture
Enter                                         aria-expanded true                                    Layer options, SMAP soil moisture
Space                                         aria-expanded false                                   Layer options, SMAP soil moisture
Enter again                                   aria-expanded true                                    Layer options, SMAP soil moisture

Tab from the trigger, seven stops             Show SMAP soil moisture;
                                              Opacity, SMAP soil moisture;
                                              Move SMAP soil moisture up;
                                              Move SMAP soil moisture down;
                                              Pin date, SMAP soil moisture;
                                              Compare, SMAP soil moisture;
                                              Layer options, SMAP L4 surface soil moisture

focus `Opacity, SMAP soil moisture`,          paint 0.55 -> 0.6 -> 0.55                             Opacity, SMAP soil moisture
ArrowRight then ArrowLeft                     (0.05 per step)

focus `Move SMAP L4 surface soil moisture     stack [smap-l3, smap-l4-surface, smap-l4-root]        Move SMAP L4 surface soil moisture up
up`, Enter                                    -> [smap-l4-surface, smap-l3, smap-l4-root]

focus `Pin date, SMAP soil moisture`,         aria-pressed true, row shows `pinned`                 Pin date, SMAP soil moisture
Enter                                         aria-pressed false, `pinned` gone after Space
```

Verdict: Tab reaches the trigger, the opacity range, both move buttons, the pin toggle and,
for a tile layer, the compare toggle; Enter and Space each toggle the row; the arrows move
the paint opacity by 0.05 per step; a move changes the stack index and keeps focus on the
same button; the pin follows `aria-pressed` and the word `pinned` appears only while it is
true.

Reproduce: open the app at 1440x900, focus the row trigger with the keyboard and repeat the
keys above.

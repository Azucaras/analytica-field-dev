## As regras que mantêm isto útil

1. Um fato vive em uma página. Linke para ela a partir de outras em vez de copiar.
2. Uma página que informa um número ou um comando informa também a data e a máquina em que foi verificado.
3. Um achado sem linha de evidência é uma opinião e pertence às notas de design.
4. Uma questão sem responsável é uma preocupação, não uma questão.

## O que este site não é

Ele não é o dossiê. O dossiê é a fonte profunda e citada, e vive neste mesmo site em [Dossiê](/pt-br/50-dossier/) e como `field-shift-dossier.md`. Quando os dois divergirem, o dossiê prevalece e a página de trabalho é corrigida.

## Onde o dossiê fica

Cada subseção do dossiê é uma página em [Dossiê](/pt-br/50-dossier/), uma por subseção na ordem do relatório, com [todas as 150 fontes](/pt-br/50-dossier/99-sources/) listadas uma vez. O dossiê também existe como arquivo único, [field-shift-dossier.md](/pt-br/), com o [registro de proveniência](/field-shift-provenance.md). Ele é a fonte de todo número aqui.

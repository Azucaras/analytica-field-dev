## O que é este site

A documentação de trabalho de uma entrada da NASA Space Apps 2026 para o desafio Field Shift: uma ferramenta de apoio à decisão que ajuda o produtor a ponderar opções de rotação de culturas frente a restrições de solo, água e mercado, usando observação por satélite, com um mapa interativo, um agente que responde perguntas sobre os dados e controle por voz.

Duas portas para o mesmo conteúdo. As páginas de pesquisa trazem as evidências, incluindo as partes que argumentam contra a versão fácil da ideia.
